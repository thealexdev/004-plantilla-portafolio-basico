# Portafolio reutilizable

Todo el contenido que se muestra en el portafolio se edita desde `src/config/portfolio.json`.

- `site`: titulo, idioma y favicon.
- `perfil`: datos personales, enlaces, CV y ruta de avatar.
- `textos`: etiquetas, titulos, botones, formulario y pie de pagina.
- `experiencia`, `proyectos` y `tecnologias`: contenido de cada seccion.

Las imagenes de ejemplo estan en `public/imgs/`. Reemplazalas y actualiza sus rutas en `portfolio.json` para usar tus propios recursos.

Ejecuta `npm run dev` para desarrollo y `npm run build` para comprobar la version de produccion.
